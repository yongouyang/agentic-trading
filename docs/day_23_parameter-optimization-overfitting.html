Parameter Optimization & Overfitting Prevention

Is the parameter with the highest backtest return necessarily the best? (回测收益最高的参数，就是最好的吗？) Blindly pursuing "optimal" can trap you in overfitting. The goal: find stable parameter regions that survive into the future.

Source: knowledge-base/day_23 (IMG_6655–IMG_6662), "30天学习量化投资 · Day 23: 参数优化与防过拟合" · Extracted 2025-08-30

1What Are Parameters? — The Strategy's "Knobs"

Parameters determine how signals are calculated, thereby affecting trades and ultimately performance. Changing parameters changes everything.

conceptParameters as strategy knobs

In a dual-MA strategy, the parameters are the window sizes: MA5 (short) and MA20 (long). Change MA5→MA10 and buy/sell timing changes → trade count, holding periods, P&L distribution all shift → return, drawdown, Sharpe all change.

2Parameter Optimization — Multi-Metric Batch Testing

Don't just find the highest-return parameter — compare return, max drawdown, AND Sharpe. Choose the combination with the best risk-adjusted profile.

MA5/20 has the highest return — but its drawdown (24.76%) is also the highest. MA6/25 has the best Sharpe (1.26) with a smaller drawdown. Looking at return alone is misleading.

💡 Better selection criteria: return in the top tier + drawdown within acceptable range + Sharpe relatively high + enough trades to avoid randomness. (参数优化不是为了找到历史上赚得最多的组合，而是找到在风险可控下，性价比最高的组合。)

3What is Overfitting? — When the Curve Is "Too Perfect"

The model memorized historical noise as patterns. Looks great on history — very likely to fail in the future. (曲线太完美，反而要警惕！)

dangerOverfitting characteristics

Overfitted strategy

  • Equity curve perfectly hugs every historical fluctuation
  • Very high backtest return, but large drawdowns too
  • Change the time period or slightly adjust parameters → performance collapses
  • Essence: memorized noise, not real patterns

Non-overfitted strategy

  • Curve is relatively smooth, doesn't chase every wiggle
  • Return and drawdown are more reasonable
  • Nearby parameters show similar performance — stable
  • Essence: captured real patterns
Key warning: The more perfect the historical curve, the more dangerous the future. Reasonable fluctuations are a sign of a reliable strategy. (历史曲线越完美，未来越危险；合理的波动，才是可靠策略的标志之一！)

5Finding Stable Parameter Regions

We don't pursue single-point max return — we seek regions where nearby parameters all perform well.

Why stability matters more than peak return

Future ≠ history

Market environments change; "lucky parameters" won't persist.

Easier to execute

Small adjustments in stable regions don't cause dramatic swings.

Sound research logic

We seek patterns, not accidentally-hit points.

6Out-of-Sample Validation — Testing with "Future" Data

Validate the parameters found in the past against data they've never seen. Only then can we judge if the strategy might continue working.

validationTime split

Absolute rule: Test-period data can ONLY be used for validation — NEVER for adjusting parameters. Otherwise the test data has been "learned" too, and validation becomes meaningless. (测试区间的数据只能用来验证，不能用来调整参数！)

✓ Correct flow

  • Hypothesize → in-sample parameter test → select stable region → out-of-sample validation → if passes → strategy is usable
  • Test interval: validate only, no parameter changes
  • Results more credible, closer to future performance

✗ Wrong flow (data leakage)

  • In-sample test → out-of-sample test → unsatisfied → adjust parameters → re-test out-of-sample
  • Repeated tuning + repeated testing = test data used for optimization = overfitting
  • Looks good but performs poorly in live trading

Key principles

  • Don't pursue the historically highest-return parameter
  • Look for stable parameter plateaus, not isolated peaks
  • Strictly separate in-sample optimization from out-of-sample validation
  • Good parameters = reasonable hypothesis + stable region + out-of-sample validation passed
