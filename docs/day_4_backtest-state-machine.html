Backtest Is a State Machine (回测是一个状态机)

Use historical data, one bar at a time (一根K线一根K线), to simulate a trader's decision process — strict time order, no peeking at the future, and only three core variables: cash, position, price.

Source: knowledge-base/day_4 (IMG_6503–IMG_6510), "30天学习量化投资 · Day 4: 回测是一个状态机" · Extracted 2026-08-30

1What a Backtest Really Is

A backtest is not predicting the future — it is simulating past trading decisions (回测不是预测未来，而是模拟过去的交易决策过程).

A backtest is a program that runs forward one bar at a time, in strict time order — like a trader who only knows the present.
It cannot jump, cannot look back at tomorrow, and at every point in time may only use information available at or before that point.

⏱ ORDER

Strict time order (按时间顺序)

The backtest must run forward one bar at a time — no skipping, no looking into the future.

🚫 NO PEEKING

No future data (不能偷看未来)

Using future data at the current point produces Look-ahead Bias (未来函数 / 前视偏差).

⚙️ SIMULATE

Simulate real trading (模拟真实交易)

Like a trader who only knows the present: decide by rules, execute, update the account.

📊 EVALUATE

Evaluate performance (评估策略表现)

Use the results to assess return, drawdown, win rate — then decide whether to optimize.

★The goal of a backtest: verify a strategy's logic and discipline in history — not to forecast tomorrow's price.

2Time Order & the Deadliest Sin: Look-ahead Bias

Why you must never use future data — and how the bias sneaks in.

The core principle (核心原则)

At bar N, the program can only see bar N and everything before it. At every point in time, use only information available at or before that point (在每一个时点，只能使用该时点及之前的信息).

✓ Usable data
过去 → 当前时点 (can be seen)
✗ Unusable data
未来 (cannot be seen)

Why future data is forbidden

不现实

Unrealistic

In real trading we never know future prices.

不公平

Unfair

Future information makes results look great — but they can't be achieved in practice.

数据污染

Data contamination

The strategy looks great in history but fails in live trading.

✓ Correct: only past data (只使用过去数据)

  • Decide using data at or before the current point only.
  • Future bars stay unknown until the loop reaches them.
  • Result: realistic and executable (真实可执行).

✗ Wrong: using future data (使用未来数据)

  • Future information is used early to make decisions.
  • The equity curve looks perfect, but is impossible to reproduce.
  • Result: false results, untradeable (虚假结果，无法真实交易).

Five common Look-ahead Bias scenarios (常见场景)

#ScenarioExample
01Using today's close to decide today's trade (使用当天收盘价计算指标并交易当天)Compute MA with today's close, then trade today on that signal.
02Computing indicators with future data (使用未来数据计算指标)Use the next N days' highs/lows to compute a moving average.
03Screening stocks with future data (筛选股票时使用未来数据)Screen by future financials or future price moves.
04Tuning parameters on the full dataset (调参时使用整段数据)Search the "best" parameter set over all of history at once.
05Using future fundamentals / dividends (使用未来的基本面、分红等信息)Backtest with earnings, dividends, or announcements published later.

The harm of look-ahead bias (前视偏差的危害)

🏆 结果虚假

False results

Returns are overstated; the curve looks perfect but can't be reproduced live.

💀 策略失效

Strategy failure

Performance after going live is terrible — even persistent losses; confidence is shattered.

💰 资金损失

Real losses

Real money is deployed on a wrong backtest conclusion, causing actual losses.

🧭 误导决策

Misled decisions

Wrong conclusions poison later research directions and investment decisions.

★The soul of backtesting: use only past and present data — never peek at the future (只能使用过去和当下的数据，绝不能偷看未来). You cannot "time-travel"!

3The Daily Loop — What Happens in One Day?

Every trading day, the program runs the same fixed six steps. This is the core loop of a backtest (回测的核心循环).

1 · Read today's data
读取当天数据
Get today's open, high, low, close, volume.
→
2 · Compute indicators
计算指标
MA, MACD, RSI… from current + historical data.
→
3 · Generate signal
产生信号
Per strategy rules: buy / sell / hold today?
→
4 · Check position state
判断持仓状态
Flat or holding? How many units?
→
5 · Execute trade
执行交易
Given signal + state: buy, sell, or do nothing.
→
6 · Update account
更新账户
Cash, position, market value, equity, P&L.
After the 6 steps, move to the next day and repeat — day after day (日复一日，循环运行) until the backtest ends.

Day51412.0––空仓 Flat100,000

Day71614.0MA5>MA20不动 Hold持仓 Long85,000*
  • Day6: a buy signal appears while flat → buy; cash decreases; state switches to Long.
  • Day7: still a buy signal, but already holding → do nothing; wait for the next signal.
  • Every day is processed strictly through the 6 steps, keeping results objective and reproducible.
⚠️ On Day6, the MA5 / MA20 used for the decision may only be computed from Day6-and-earlier data — never Day7's close!
Remember: a backtest is not computing results — it is simulating a trader's decision process.
(回测不是算结果，而是模拟交易者的决策过程！) A good backtest system is a program that runs in strict time order, like a trader "who only knows present information". Only then do results have reference value for real trading.
★Follow the daily loop strictly, and the backtest result becomes trustworthy (严格遵循每日流程，才能得到可信的回测结果).

4The State Machine View (有限状态机, FSM)

The essence of a backtest: at every point, decide how to act and switch state based on the current state and the signal.

What is a state machine?

A Finite State Machine consists of a set of states, events (signals), and transition rules. The system is in exactly one state at any moment, and switches between states according to rules. The simplest trading strategy has only two states:

空仓
No Position (Flat)
买入信号 Buy signal → 满足条件 → 买入 → switch to Long
持有信号 Hold signal → 不满足任何条件 → stay in current state
卖出信号 Sell signal → 满足条件 → 卖出 → switch to Flat
持仓
Long Position

The three transition rules (状态如何转换)

RuleCurrent state + signalActionNext stateExample condition
①空仓 Flat + buy signal (买入信号)Buy持仓 LongMA5 > MA20 → buy
②持仓 Long + hold signal (持有信号)Do nothing (不动)持仓 LongMA5 > MA20 still true → keep holding
③持仓 Long + sell signal (卖出信号)Sell空仓 FlatMA5 < MA20 → sell, back to flat
💡 At any moment the system is in exactly one state; a transition happens only when its condition is satisfied.

Properties of a state machine (状态机的特点)

状态有限

Finite states

Only a handful of states exist.

规则明确

Explicit rules

Transitions are triggered by well-defined signals.

时序驱动

Time-driven

Advances step by step along time.

可扩展

Extensible

More states and rules can be added later.

State machines in everyday life

🚦 Traffic light

  • Red → condition met → Green
  • Green → condition met → Yellow
  • Yellow → condition met → Red
  • At any moment it is exactly one color.

🚗 Driving (simplified)

  • Parked (空仓) → step on gas (买入) → Driving (持仓)
  • Driving (持仓) → step on brake (卖出) → Parked (空仓)
  • Likewise, when each bar arrives, the system uses its current state and the signal to decide the next action and state.
★Writing strategies with state-machine thinking gives clearer logic and more robust code (用状态机思维写策略，逻辑更清晰，代码更健壮) — and makes the strategy easier to implement and debug.

5State Transitions in Action — the Dual-MA Example

At every point only one of three cases can happen: buy-in, hold, or sell-out. A full 15-day dual moving-average walkthrough.

① 空仓 + 买入信号 → 持仓

  • Rule: MA5 > MA20 produces a buy signal.
  • Meaning: no position; condition now met → establish a long position.
  • Action: buy; switch to Long.

② 持仓 + 持有信号 → 不动

  • Rule: MA5 > MA20 keeps producing a hold signal.
  • Meaning: already holding; condition still met → nothing to do.
  • Action: hold; stay Long.

③ 持仓 + 卖出信号 → 空仓

  • Rule: MA5 < MA20 produces a sell signal.
  • Meaning: holding; condition no longer met → exit.
  • Action: sell; switch to Flat.

  • Sell signal + Long → sell → Flat
★ Remember: at every point only one of the three cases occurs — this is the core of the backtest state machine.
★A backtest is a state machine: rules drive state transitions, simulating the real trading process (回测就是一个状态机：根据规则，驱动状态转换，模拟真实交易过程).

6The Three Core Variables (回测最核心的三个变量)

Throughout the whole backtest, these three variables change continuously, driving the account and position state.

① cash（现金）

cash — available funds

Remaining usable funds in the account. Decreases when buying, increases when selling.

Example: start cash = 100,000 → spend 80,000 → cash = 20,000 → sell for 85,000 → cash = 105,000.

② position（持仓数量）

position — units held

How much of the asset you currently hold — decides how much you can sell and how much you earn.

Example: buy 1,000 shares → position = 1,000 → sell all → position = 0.

③ price（价格）

price — current bar's price

Usually the close. All calculations and trades are based on it: indicators (MA5, MA20), P&L, and cash changes.

Example: Day-10 close = 25, used for position market value and trade amounts.

💡 The essence of a backtest: at every point in time, update these three variables and record the changes of account and position.

How the variables relate (三个变量的关系)

  • price × trade size = trade amount → affects cash.
  • price × position = market value → affects P&L.
  • Trading actions move value between cash and position.
★ Without these three variables, you cannot simulate a real trader in history!

✗ Common pitfalls (常见误区)

  • Recording only returns, not the variables — you can't replay the trading process or the equity curve.
  • Ignoring price changes — position may be unchanged, but price moves still change P&L.
  • Wrong update order — you must first generate the signal, then trade according to state, and only then update the variables.

✓ Correct: at every point, strictly follow the loop to update cash, position, price.

★Master these three variables and you master the backtest's underlying driving logic (掌握了回测的"底层驱动逻辑").

7Your Practice — Dual-MA Strategy Backtest Rules

Based on MA5 and MA20, trade according to the state machine and its three cases (双均线策略回测规则).

Strategy rules (策略规则)

① Flat & MA5 > MA20 → BUY (买入)

  • When the condition is met, switch from Flat to Long.
  • Buy with all available cash.
  • State transition: 空仓 → 持仓.

② Long & MA5 > MA20 → HOLD (不动/持有)

  • Keep the current position; neither buy nor sell.
  • State stays unchanged.
  • State transition: 持仓 → 持仓.

③ Long & MA5 < MA20 → SELL (卖出)

  • When the condition is met, sell the entire position.
  • Switch back to Flat.
  • State transition: 持仓 → 空仓.
⚠️ All judgments, signals and trades must be completed after each day's close, using only that day's and earlier information — never future data (所有判断只能基于当天及之前的数据)!

Key moments in the full example (关键节点说明)

🛒 Day10 — buy trigger

First golden cross

MA5 crosses above MA20 for the first time → switch from Flat to Long, buying with all available cash.

⏸ Day11–Day14 — hold

Stay the course

MA5 stays above MA20 → keep holding, no operation.

🛒 Day15 — sell trigger

Death cross exit

MA5 crosses below MA20 → sell the entire position, back to Flat.

Day 4 summary (Day4 学习总结)

  • A backtest must run in time order — never peek at the future.
  • A backtest can be understood as a state machine: 空仓 Flat ↔ 持仓 Long.
  • State transitions are decided by the signal and the current state together.
  • The core variables are only three: cash, position, price.
  • The dual-MA strategy is simple, but the backtest logic must follow the rules strictly.
  • Execute the loop strictly every day — that is what makes the result trustworthy.
★Strict process + correct state machine = trustworthy backtest results (严格的流程 + 正确的状态机 = 可信的回测结果). A backtest is not for predicting the future — it verifies a strategy's logic and discipline in history.
