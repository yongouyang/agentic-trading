Performance Analyzer — Evaluating Strategy Quality

Backtest is done — now the question: is this strategy actually good? (这个策略到底好不好？) High returns alone ≠ good strategy. Excellent strategy = high returns + controlled risk.

💡 Performance Analyzer is responsible for "evaluating", not "trading". It doesn't care what you bought, how, or when. It only asks: what's the result? How much risk? Is it worth it? (Performance Analyzer 负责"评价"，不负责"交易"。)

2Core Metric ①: Return — How Much Did You Earn?

Return measures the strategy's overall earning ability — the most intuitive metric, but it cannot alone represent strategy quality.

metricReturn formula

Return (收益率)= Final Equity − Initial Equity÷ Initial Equity× 100%
Example Initial capital: 1,000,000 · Final equity: 1,200,000
Return = (1,200,000 − 1,000,000) / 1,000,000 = +20%

Key points

  • Higher is better — but high return alone is not sufficient
  • High returns from bearing extreme risk may not be sustainable
  • Return only shows the result, not the process — it could have experienced massive drawdowns along the way
  • Goal: pursue long-term, stable, sustainable returns — not short-term windfalls
💡 Return tells us "how much this strategy earned". But truly excellent strategies also need to show how much risk they bore in the process. (收益率告诉我们策略最终赚了多少，但真正优秀的策略还需要看它在赚钱过程中承担了多大的风险。)

3Core Metric ②: Max Drawdown — The Worst Pain

Max drawdown measures the largest decline from a historical peak — representing the "most painful moment" during the strategy's run.

metricMax Drawdown formula

Max Drawdown= Peak − Subsequent Trough÷ Peak× 100%
Example Historical peak: 1,200,000 · Subsequent lowest point: 900,000
MDD = (1,200,000 − 900,000) / 1,200,000 = −25%

Two strategies compared

Strategy A: high return, high drawdown

Peak: 1,300,000 → Trough: 850,000
MDD = −34.6%

Earned a lot in the end, but the journey was agonizing.

Strategy B: moderate return, low drawdown

Peak: 1,150,000 → Trough: 1,030,000
MDD = −10.4%

Earned less, but much smoother ride.

💡 The smaller the MDD, the more robust the strategy — less risk endured, smaller drawdowns. How much drawdown you can tolerate determines how much return you can hold onto. (控制回撤，就是控制"生存风险"。你能忍受多大的回撤，决定了你能拿住多少收益。)

4Core Metric ③: Sharpe Ratio — Is the Risk Worth It?

Sharpe measures "excess return per unit of risk" — considering both return and volatility together.

metricSharpe Ratio formula

Sharpe Ratio= Rp − Rf÷ σp

Rp = strategy annualized return · Rf = risk-free rate (~2%) · σp = annualized volatility (std dev)

Example comparison

Strategy A

Annual return30%
Risk-free rate2%
Volatility35%
Sharpe(30−2)/35 = 0.80

Strategy B

Annual return22%
Risk-free rate2%
Volatility12.5%
Sharpe(22−2)/12.5 = 1.60

Strategy A earns more, but with much bigger swings. From a risk-adjusted perspective, Strategy B is superior.

Sharpe reference scale

< 0
Worse than risk-free
0 ~ 1
Average
1 ~ 2
Good
2 ~ 3
Excellent
> 3
Exceptional (rare)
💡 Sharpe is not a universal metric — it can't fully represent extreme risks (black swans). Always pair it with Max Drawdown. Also: Sharpe depends on historical data; different strategies/markets can't be directly compared — only meaningful within the same market and period.

★Strategy comparison isn't about who earns the most — it's about who can earn longer under controlled risk. In the real world, survive first, then compound. High returns must be exchanged for risk — the key question is how much risk you're willing to bear. (策略不是比谁赚得最多，而是比谁能在可控风险下，赚得更久！)

6Performance Analyzer — Go Design

Input: equity curve. Output: Performance Report with all metrics.

goStruct design

type EquityPoint struct {
    Time  time.Time
    Value float64
}

type PerformanceReport struct {
    Return          float64 // total return
    MaxDrawdown     float64 // maximum drawdown
    Sharpe          float64 // Sharpe ratio
    WinRate         float64 // win rate
    ProfitLossRatio float64 // profit/loss ratio
    CalmarRatio    float64 // Calmar ratio
    // ... more metrics
}

type PerformanceAnalyzer struct {
    RiskFree  float64       // risk-free rate
    Equity    []EquityPoint // equity curve
    Frequency int           // 252 (daily), 52 (weekly), etc.
}
