Parameter Optimization & Overfitting

Why the most profitable parameters in backtests might be the most dangerous in live trading. (为什么回测里最赚钱的参数，实盘反而可能最危险？) Historical data has already happened — the future is the real test.

★Overview — The Optimization Trap

Parameter optimization is not about finding the historically most profitable number — it's about finding rules that work across a broad range of conditions and continue to work in the future.

Identifying the essence — avoid being fooled by historical data.

★Core takeaway: Parameter optimization is not about finding the single highest-return number in history — it's about finding a region where the strategy is effective and will continue to work in the future. Historically optimal parameters ≠ future optimal parameters! (历史最优的参数，不一定是未来最优的参数！)

1What is Overfitting?

Backtest returns are sky-high, but live trading loses money — why? (回测里收益很高，为什么实盘却亏了？)

definitionOverfitting: over-tuning parameters to fit historical noise

Overfitting (过拟合) means adjusting strategy parameters so aggressively that the strategy performs brilliantly on historical data, but cannot adapt to future market changes. (过度调整策略的参数，使它在历史数据上表现极好，但无法适应未来的市场变化。)

Good strategy (好的策略)

  • Finds the real pattern behind historical data (找到历史数据背后的规律)
  • Simple, stable, generalizable (简单、稳定、能泛化)
  • Still effective in the future (在未来也可能有效)

Overfitted strategy (过拟合的策略)

  • Treats noise as pattern (把历史数据的噪声也当成规律)
  • Overly complex, tightly fitted to noise (过于复杂、紧贴噪声)
  • Likely to fail in the future (未来很可能失效)

Programmer analogy (程序员类比)

Normal approach

// Find a pattern, solve a class of problems
def solve(problem):
    return general_algorithm(problem)

Works on new data too — truly learned the pattern.

Overfitted approach

// Memorize historical answers
def solve(problem):
    if problem in history_data:
        return history_answer[problem]
    else:
        return None

Crashes on new data — just memorized the answers.

Typical signs of overfitting (过拟合的典型表现)

  • Extremely high backtest returns, but poor live trading results (历史回测收益极高，实盘表现差)
  • Out-of-sample test performance drops significantly (样本外测试表现明显变差)
  • Parameters are very sensitive — small changes cause large performance drops (参数非常敏感，稍微变动就大幅下降)
  • Many parameters needed to "tune" good results (需要很多参数才能"调出"好结果)
  • Model/strategy structure is abnormally complex (模型/策略结构异常复杂)
💡 Historical performance being good doesn't mean future performance will be good. Don't be fooled by the "illusion" of historical data. (历史表现好，不代表未来一定好。不要被历史数据的"假象"迷惑。)

2Parameter Plateau vs Isolated Peak

Rather than chasing a single extraordinary high point, prefer a broad region where everything works well. (宁可选一片都不错的区域，也不要迷信一个异常高点！)

Stable: Parameter Plateau (参数平台) ✓

Neighboring parameters produce similar returns, forming a "plateau" — the strategy is stable.

An entire region works — changing parameters slightly doesn't matter much. More likely to represent a real pattern, not a coincidence.

Dangerous: Isolated Peak (孤立峰值) ✗

Only one point is exceptionally high; surrounding parameters are poor — likely historical coincidence.

One point is abnormally high — likely captured noise. Change parameters slightly and performance drops dramatically in the future.

Why MA7 is unreliable:

  • Surrounding parameters vary wildly — they don't support MA7 as a real pattern (周围参数表现差异很大，不支持它是真正的规律)
  • Likely captured historical noise or coincidental events (很可能捕捉到历史噪音或偶然事件)
  • Change the time period or market, and returns may plummet or turn negative (换个时间段或市场，收益可能大幅下降甚至转亏)
  • It's not "real skill" — it's a "historical coincidence" (它不是"真本事"，而是"历史巧合")

4Out-of-Sample Testing — Don't Let the Strategy Peek at the Answers

Split data into training (for tuning) and validation (for testing). Never cross the boundary. (别让策略偷看答案。)

validationThe two-period approach

📚
Training period (训练集)
2015–2022 · find patterns, tune parameters
⫿
📝
Out-of-sample (样本外)
2023–2025 · validate, no more tuning

Training set = teacher's practice problems (训练集 = 老师出的题)

  • Use historical data to find patterns and tune parameters (用历史数据找规律、调参数)
  • Try different parameter combinations iteratively (不断尝试不同参数组合)
  • Goal: make the strategy profitable on history (目标：在历史上尽量赚钱)

Out-of-sample = the real exam (样本外 = 正式考试)

  • Use future data to validate the strategy (用未来数据验证策略)
  • No more parameter tuning — only validate (不再调参数，只验证效果)
  • Simulates real trading environment (模拟真实交易环境)
  • Goal: test if the strategy can profit in the future (目标：检验策略是否能未来赚钱)
Programmer analogy: If you use the exam questions to practice, you're just memorizing answers — not actually learning. Same with strategies: if you tune on all available data, you have no way to test whether the strategy truly works. (如果拿考试题来练习，那只是把答案背熟，不是真正学会了！)

Core principles (核心原则)

  • Don't seek the single highest-return parameter — seek parameters that are stable across a region (不寻找收益最高的单一参数，而寻找在一片区域内都稳定有效的参数).
  • Adjacent returns close together = stable (相邻收益接近 = 稳定): strategy is insensitive to parameter changes, more likely reflecting real patterns.
  • Single-point extremely high return = don't pick (单点收益特别高 = 不选): isolated spike = highly suspicious, probably noise.
  • Don't push returns from 20% to 40% by endlessly tuning — over-tuning = overfitting risk explodes (过度调参 = 过拟合风险大增).
💡 More precise statement: Overfitting doesn't guarantee losses — but its historical performance has low credibility, and future returns may drop significantly or even turn negative. (过拟合不一定必然亏损，但其历史表现的可信度很低，未来收益可能显著下降甚至转亏。)
