Bar, Signal, Position & Portfolio — Core Data Structures

Turn "market data, signals, positions, account" into real data structures in the program — structured, continuously updated, computed, and evaluated. (把"行情、信号、持仓、账户"变成程序里真正的数据结构。)

1Overview — Four Core Data Structures

The essence of a quant system: express trading ideas as structured data, then continuously update, compute, and evaluate. (量化系统的本质，是把交易想法用结构化数据表达出来，并且持续更新、计算和评估。)

行情输入

Bar

Market input (行情输入) — one candlestick (K 线) at a time: OHLCV for a time period.

策略输出

Signal

Strategy output (策略输出) — buy / sell / hold as a suggestion (建议), with a position ratio and a reason.

持仓状态

Position

Position state (持仓状态) — what is held, how much, at what cost, and the current price.

账户整体

Portfolio

The whole account (账户整体) — cash, positions, total equity; continuously updated.

2Bar — What Does One Candlestick Look Like in Code?

A Bar is the smallest unit of market data a quant system processes — it represents the market's behavior over one time period.

marketBar — the market-data atom

type Bar struct {
    Time   time.Time // 时间戳 timestamp
    Symbol string    // 交易标的 instrument
    Open   float64   // 开盘价 open price
    High   float64   // 最高价 high price
    Low    float64   // 最低价 low price
    Close  float64   // 收盘价 close price
    Volume float64   // 成交量 volume
}
💡 A Bar only describes the market — it contains no trading logic whatsoever (不包含任何交易逻辑).
Bar ↔ candlestick mapping (Bar 与 K 线图的对应关系):
FieldMeaning
High (最高价)Highest price within the period
Open (开盘价)Price at the start of the period
Close (收盘价)Price at the end of the period
Low (最低价)Lowest price within the period
💡 Green candle: Close > Open (上涨, rising) · Red candle: Close < Open (下跌, falling).
Bars of different periods (不同周期的 Bar):
PeriodMeaningCommon use
1-minute Bar1 minute of market dataShort-term strategies, intraday trading (短线策略、日内交易)
Daily Bar1 day of market dataMid/long-term trend strategies (中长线趋势策略)
Weekly Bar1 week of market dataTrend judgment, swing strategies (趋势判断、波段策略)
Monthly Bar1 month of market dataLong-term investing, macro analysis (长线投资、宏观分析)
Example: one daily Bar (日线 Bar) for 2024-07-01 Open: 10.00 · High: 10.50 · Low: 9.80 · Close: 10.20 · Volume: 120,000

Historical data is simply a series of consecutive Bars (历史数据就是一系列连续的 Bar), processed one by one in time order (按时间顺序一根根处理).

★Summary (小结): A Bar is the smallest unit of market data. It carries OHLCV information, used to compute indicators and generate signals. A quant system processes Bars one at a time, in time order.

3Signal — The Strategy Only Outputs a Suggestion

A Signal is produced by the Strategy; it expresses "what I want to do" (想要做什么), but does not modify the account directly.

strategySignal — the trade-suggestion memo (交易建议说明书)

type Signal struct {
    Time   time.Time // 信号产生的时间 when generated
    Symbol string    // 交易标的 instrument
    Action Action    // 动作 buy / sell / hold
    Ratio  float64   // 仓位比例 position ratio (0~1)
    Reason string    // 产生信号的原因 why
}
💡 A Signal is only a suggestion. Whether it is finally executed is decided by Risk and Broker — the Signal itself never modifies Cash and Position; it only tells the system the idea.
Action enum (Action 枚举):
ActionMeaning
BUYSuggest buying, allocating funds by Ratio. Ratio = 1.0 means full position (满仓买入).
HOLDSuggest holding, no trade. Ratio is usually 0.
SELLSuggest selling Ratio of the position. Ratio = 1.0 means sell everything (全部卖出).

Signal examples (Signal 示例)

TimeSymbolActionRatioReason (原因)Meaning
2024-07-01 10:00AAPLBUY0.6Broke above Bollinger upper band (突破布林带上轨)Buy AAPL with 60% position
2024-07-01 10:05AAPLHOLD0Trend unchanged, keep holding (趋势未变，继续持有)No trade, keep current position
2024-07-01 10:10AAPLSELL1.0Broke below the moving average (跌破移动平均线)Sell the entire AAPL position

A Signal only travels as a suggestion between Strategy and Risk (Signal 只在 Strategy 和 Risk 之间传递建议).

A good Signal should be (一个好的 Signal 应该具备)

  • Clear (明确) — knows what to do and when.
  • Explainable (可解释) — the Reason is traceable.
  • Quantifiable (可量化) — Ratio gives the position size.
  • Never oversteps (不越权) — never modifies account state directly.
💡 Keep the Signal simple and pure, and the system stays stable and testable (保持 Signal 简单、纯粹，系统才更稳定、可测试).
★Summary (总结): A Signal is the strategy's "trade-suggestion memo" — it executes nothing, and only expresses: at what time, for which instrument, what it wants to do, and why. Remember: Signal ≠ trade. It is an "idea", not an "action"! (Signal ≠ 交易，它只是"想法"，不是"动作"！)

4Position — What Must One Holding Record?

A Position represents the account's current holding state in one instrument.

portfolioPosition — the basic building block of a Portfolio

type Position struct {
    Symbol       string  // 标的代码 instrument code
    Quantity     float64 // 持仓数量 (+long, −short)
    AveragePrice float64 // 持仓平均成本价 avg cost
    MarketPrice  float64 // 当前市场价格 current price
}
💡 The three core elements of a position (持仓的核心三要素): quantity, cost, current price (数量、成本、当前价). With Quantity, AveragePrice, MarketPrice, you can compute the floating P&L (浮动盈亏).
The four key fields (持仓的四个关键字段):
FieldMeaning
SymbolWhich instrument is held (持仓的标的是谁)
QuantityHow many shares are held (positive for longs 多头为正)
AveragePriceAverage buy cost — the lower the better (越低越好)
MarketPriceCurrent market price — changes in real time (实时变化)

Worked example: AAPL (持仓示例)

Establish the position (建立持仓)
Buy time2024-07-01 10:00
Buy price20.00
Buy quantity3,000 shares
Position cost20.00 × 3,000 = 60,000
Current position state (当前持仓状态)
SymbolAAPL
Quantity3,000
AveragePrice20.00
MarketPrice22.00
Current floating P&L (当前浮动盈亏) Floating P&L = (current price − cost) × quantity
= (22.00 − 20.00) × 3,000
= 6,000 (profit 盈利)

Long vs short (多头 vs 空头)

Long (多头, 做多)Short (空头, 做空)
Buy → price rises → profit (价格上涨盈利) → sell to close (卖出平仓)Sell to open (卖出开仓) → price falls → profit (价格下跌盈利) → buy to close (买入平仓)

Notes (注意事项)

  • Quantity > 0 → long position (多头).
  • Quantity < 0 → short position (空头).
  • Quantity = 0 → no position (空仓); after closing (平仓后), Quantity becomes 0.
  • AveragePrice is usually updated on opening / adding to the position (开仓/加仓时更新).

AveragePrice update rules (多头示例, long example)

Action (操作)PriceQuantityPosition quantity (持仓数量)Average price (持仓均价)
First buy (第一次买入)20.001,0001,00020.00
Add (第二次加仓)22.001,0002,00021.00
Partial sell (部分卖出)23.00−5001,50021.00
Sell all (全部卖出)23.00−1,50000
  • After adding (加仓后): new average price = total cost / total quantity (新的均价 = 总成本 / 总数量).
  • After selling (卖出后): quantity decreases, average price unchanged (数量减少，均价不变).
  • After selling everything (全部卖出后): quantity = 0, average price resets to 0 (均价清零).
★Summary (小结): A Position records the holding state in one instrument and is the basic unit of a Portfolio. It lets us always know: how much is held, at what cost, and what it is worth now (持了多少、成本多少、现在值多少).

5Portfolio — The Account's Overall State

A Portfolio manages our cash and all positions — it is the core for computing total equity (总权益).

portfolioPortfolio — the account snapshot (账户快照)

type Portfolio struct {
    Cash      float64                // 账户现金 account cash
    Positions map[string]*Position   // 持仓集合 position set
}
  • Cash (现金) — usable for buying, paying fees, maintaining positions, etc.
  • Positions (持仓) — the state of all holdings, keyed by Symbol.
  • One Portfolio can manage multiple Positions — each Symbol maps to exactly one Position (每个 Symbol 对应一个 Position).
💡 Portfolio = account snapshot (账户快照), reflecting the true state of the account at any time.
Example portfolio (Portfolio 示例) Cash (现金): 40,000 · total positions: 2 instruments

Cash 40,000+ Market value 226,000= Equity 266,000

★Summary (小结): A Portfolio holds the account's overall state — cash + all positions. Equity = cash + position market value. The Portfolio updates once per trade; in backtests and live trading we always evaluate the strategy through it. Remember: the Portfolio is your "account snapshot" — it tells you what you're worth right now.

6Equity — How to Compute Total Account Value

Total equity reflects the account's true current value — the core metric for evaluating returns and risk.

equityEquity = Cash + All Position Market Value (所有持仓市值)

Equity (总权益)= Cash (现金)+ Σ (Quantity × MarketPrice)
  • Cash (现金) — unused funds in the account.
  • All position market value (所有持仓市值) — the sum of each position's quantity × current market price.
  • Position market value = Σ (Quantity × MarketPrice). Use the latest MarketPrice for the most accurate Equity (使用最新的 MarketPrice 才能得到最准确的 Equity).
💡 In one sentence (一句话理解): total equity = money in your pocket + what all your assets are worth. It changes continuously with price movements and trading (总权益会随着价格波动和交易不断变化).

Worked example (计算示例)

Position market value (持仓市值的计算方式):
SymbolQuantityMarketPriceMarket value
AAPL3,00022.0066,000
MSFT500320.00160,000
Total226,000
Current account state Cash: 40,000 · Positions: 2 instruments

Equity = Cash + position market value
= 40,000 + 226,000
= 266,000

Equity change scenarios (Equity 的变化场景)

After buying (买入后)
Equity roughly unchanged (cash ↔ market value)
→
Price rises (价格上涨)
Equity rises
→
After selling (卖出后)
Cash increases, Equity reflects the change
  • Equity rises when position market value increases or cash increases (持仓市值增加 或 Cash 增加).
  • Equity falls when position market value decreases or cash decreases (持仓市值减少 或 Cash 减少).

Factors that can affect Equity (可能影响 Equity 的因素)

Price moves (价格波动)

Market prices rise and fall.

Trading (交易行为)

Buying, selling, rebalancing (买入、卖出、调仓).

Cash changes (现金变动)

Deposits, withdrawals, fees (入金、出金、费用).

Fees / slippage (手续费/滑点)

Transaction costs reduce Equity.

Dividends / interest (分红/利息)

Dividends increase Cash.

Risk control (风险控制)

Stop-losses can reduce Equity (止损可能导致 Equity 下降).

★Summary (小结): Equity = Cash + all position market value. It reflects the account's true value and P&L; every decision, risk rule, and evaluation revolves around Equity. No matter how complex the strategy, the ultimate goal is steady Equity growth! (不管策略多复杂，最终目的都是让 Equity 稳定增长！)

7Position Sizing — How It Shapes Returns (仓位对收益的影响)

The same instrument move produces very different account returns under different position sizes (同样的标的涨跌，不同的仓位，会直接改变账户的收益).

Account return ≈ instrument return × invested position ratio (账户收益率 ≈ 标的收益率 × 投入仓位比例)
Example: the instrument rises 10%, but the account invests only 60% of funds → account return ≈ 10% × 60% = 6%.

Returns at different position sizes (标的上涨 10%)

Invested ratio (投入仓位比例)Account return (约)Note (说明)
100%10%Full position — maximum return, maximum risk (满仓，收益最大，但风险也最大)
60%6%Return amplifier of 0.6 (收益放大系数 0.6)
30%3%Return amplifier of 0.3
10%1%Return amplifier of 0.1
0%0%Empty position — no return, no risk (空仓，无收益也无风险)

Why is position sizing so important? (为什么仓位很重要)

Return amplifier (收益的放大器)

Higher position → bigger returns; but also bigger drawdowns and volatility (仓位越高，收益越大；同时，回撤和波动也越大).

Core of risk control (风险控制的核心)

Position sizing limits single-trade losses and maximum drawdown (通过控制仓位，限制单笔亏损和最大回撤).

Key to long-term survival (长期生存的关键)

Only by surviving long enough do you get the chance to earn more (活得久，才有机会赚得多).

✗ Position too high (仓位过高, e.g. full position 满仓)

  • Potentially higher returns (收益可能更高)
  • But much larger drawdowns (回撤更大)
  • More violent volatility (波动更剧烈)
  • Easy to blow up the account (容易爆仓)

✓ Moderate position (仓位适中, e.g. 50%–80%)

  • Relatively stable returns (收益相对稳定)
  • Controllable drawdowns (回撤可控)
  • Better long-term compounding (长期复利更优)
  • Better long-term survival (更利于长期生存)

Key points (关键要点总结)

  • The instrument's move determines the instrument return (标的涨跌决定"标的收益率"); position size determines the account return (仓位决定"账户收益率"的大小).
  • Account return ≈ instrument return × invested position ratio.
  • Controlling position size is one of the core methods for controlling risk and achieving long-term stable returns.
★Direction is decided by the strategy; success or failure is decided by position size (方向由策略决定，成败由仓位决定). Position size is neither "the higher the better" nor "the lower the safer" — find your own position range so capital grows long-term, steadily, and continuously. Position decides how much you can earn, and how long you can survive (仓位决定你能赚多少，也决定你能活多久).

Day 7 summary (Day 7 总结)

  • Bar provides market data; Signal is the strategy's suggestion; Risk decides whether it's allowed; Broker handles execution.
  • Position records the quantity, cost, and current price of a holding.
  • Portfolio manages cash and all positions.
  • Equity = Cash + all position market value — the core metric of account performance (衡量账户表现的核心指标).
